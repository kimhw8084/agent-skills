# Agent Skills Hub

This repository is the catalog and incubation workspace for reusable agent skills.
OpenCode-oriented skills are supported first.

## Repository policy

- Early-stage skills may incubate as self-contained child directories.
- A skill graduates to its own repository when independent CI, release identity,
  evidence history, or project-level automation benefits from a dedicated Git boundary.
- Dedicated projects remain cataloged here; their source of truth lives in their own repository.
- New child skills use kebab-case, a local `AGENTS.md`, installation/verification paths,
  and explicit provenance.
